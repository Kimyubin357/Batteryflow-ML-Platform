# 품질 보증 — 현재 화면·모델·판정 근거

기준일은 2026-11-05다. 품질 보증에는 저장된 팩·공정 분석 결과 조회와 시험 데이터의 고정 PCA 분석이 있다. 팩 분석의 `battery-packs-*` 자료 버전과 시험 분석의 공식 자료 버전 `2026-11-05.v5`는 서로 다르다. 선택한 대상의 조회 결과를 기준으로 답하고 두 범위의 수치나 모델을 섞지 않는다.

## 저장된 팩·공정 분석

품질 팩 화면은 `battery_packs`에 저장된 분석 결과와 `battery_meta` 설정을 읽는다. 선택한 팩·충전 또는 방전 공정의 기존 AI OK/NG, 이상 비율, 점수 추이와 셀 스냅숏을 조회한다. 이 화면에서 저장된 AI 결과를 현재 시험용 PCA 모델로 재계산한 것은 아니다. 저장된 AI 판정, 유형 의심 규칙, 작업자 판정은 별도 정보다.

품질 팩 셀 상태는 저장된 z-score의 절댓값으로 나눈 상대 편차 표시다. 3 이상은 위험, 2 이상 3 미만은 주의, 2 미만은 정상이며 값이나 z-score가 없으면 미확인이다. 위험 셀이 곧 불량 원인으로 확정되는 것은 아니다. 셀 배열 구조가 맞지 않아 근거가 없을 때 정상 176개로 간주하지 않는다.

품질 팩의 용량·용접·와이어·센서 의심 표시는 공정별 정상 참조 지표의 평균에 모집단 표준편차 3배를 더한 임계값을 초과하는지 확인하는 규칙이다. 현재 정책은 `pack-defects-by-process-4287dcc6bb999111`이다. 용량 지표는 인접 시점 전압 변화의 최댓값, 용접 지표는 저장된 AI 최고점 시점의 평균·최저 전압 차, 와이어 지표는 같은 시점의 인접 셀 전압 차, 센서 지표는 온도 중앙값 대비 최대 편차다.

품질 팩의 의심 유형 규칙은 정상 참조 팩 번호로 적합 36개·평가 15개를 나누며 충전과 방전 임계값을 별도로 사용한다. 정상 OK 등급은 원인 4종의 확정 정답이 아니다. 이 규칙의 내부 초과율을 외부 불량 분류 정확도로 표현하지 않는다. 원천 102개 기록 중 92개는 전체 시계열 재계산 자료가 없어 제한이 있다. 현재 임계값과 의심 여부는 해당 팩·공정의 조회값을 사용한다.

## 시험 데이터의 고정 PCA 분석

품질 시험 분석의 기본 모델은 `PCA (T²·SPE)`이며 시험 설정 버전은 `PCA-T2-SPE-train10`, 고정 추론 파일 버전은 `quality-pca-existing-replay-v1`이다. 정상 10개 파일의 56,805행을 기준으로 전압 176채널·온도 32채널을 9개 지표로 요약하고 주성분 6개를 사용한다. Random Forest는 지도 비교 모델이고 Isolation Forest·LSTM Autoencoder도 연구 비교 대상이다. 이 시험 모델 설명을 팩 화면의 저장 AI 판정 생성 모델로 단정하지 않는다.

품질 시험의 T²는 학습된 주성분 공간 안에서 정상 중심과 떨어진 정도이고 SPE는 주성분으로 설명되지 않는 재구성 잔차다. 고정 관리한계는 T² 20.4268410915, SPE 2.0460330001이다. 둘 중 하나가 관리한계를 넘는 상태가 10시점 연속이면 해당 연속 구간을 이상으로 표시한다. 완료된 시험의 구간을 사후 표시하는 규칙이며 실시간 0지연 탐지를 의미하지 않는다.

품질 시험 평가 대상은 정상 `Test03_OK_chg`, `Test04_OK_dchg`와 이상 `Test06_NG_chg`, `Test07_NG_dchg`, `Test08_NG_chg`의 총 10,770시점이다. 저장된 PCA 비교 결과는 시점 단위 Precision 0.9971, Recall 0.9764, F1 0.9866, FP 10, FN 82다. 이는 셀별 원인 판별 성능이나 팩 출하 승인 정확도가 아니다. 파일 수가 적고 신규 설비·신규 불량 원인에 대한 일반화를 보장하지 않는다.

## 원인 설명과 입력 한계

품질 시험의 이상 탐지기는 원인 4종을 학습한 분류기가 아니다. `Test08`은 원자료 가이드북에 용량 불량 사례로 표기됐으나 AI의 원인 확정은 아니다. `Test07`은 본문의 센싱 와이어 불량 설명과 코드 주석의 용량 불량 설명이 달라 확인이 필요하다. `Test06`의 센서 고장 유형도 확정된 사실로 답하지 않는다. 원본 측정값 이탈은 센서·배선·BMS 등을 추가 확인할 근거다.

품질 CSV 분석은 단일 SerialNumber의 완료된 시험 10~20,000행, 30MB 이하 UTF-8 CSV를 받는다. 전압 176채널·온도 32채널과 Date·Time·SerialNumber가 필요하고 충전·방전을 직접 선택한다. 시각은 유효하고 중복 없이 증가해야 한다. 결측·범위 이탈이 전체 측정값의 20%를 넘으면 거부한다. 현재 보정 범위는 전압 2~5V, 온도 −20~100℃이며 이 범위가 현장 합격 기준을 뜻하지 않는다.

품질 CSV는 범위 밖 값을 결측 처리하고 앞뒤 보간·대체를 포함한 사후 분석을 수행한다. 원본과 보정값을 구분해 표시하고 고정 PCA·관리한계를 사용하며 업로드 자료로 재학습하지 않는다. 정답은 원본 해시와 행 ID를 확인한 뒤 평가에만 사용한다. 결과를 공식 시드에 자동 저장하지 않으며 원인 확정이나 출하 승인을 수행하지 않는다.

## 현재 근거 파일

품질의 현재 범위와 규칙은 `backend/battery_packs.py`, `backend/defect_policy.py`, `runtime/quality/defect_calibration.json`, `backend/quality_engine.py`, `backend/quality_evidence.py`, `runtime/quality/pca_frozen.json`, `runtime/validation/quality_scores.csv`, `firestore/seed/quality.jsonl`에 근거한다. 시험 성능은 시험 범위, 팩 의심 규칙은 팩 범위를 각각 명시한다.

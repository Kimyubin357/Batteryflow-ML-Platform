# BatteryFlow 현재 운영 정책

기준일 2026-11-05. 현재 포함된 공식 분석 자료는 dataVersion `2026-11-05.v5`, schemaVersion 3, 275개 문서다. 발주 모델 버전은 `audited_v3`다. 실제 답변의 자료 버전·선택 모델·대상·수량은 서버가 조회한 SCREEN을 기준으로 확인한다. 이 문서의 기준일은 개별 데이터의 관측일이나 실시간 설비 수집 시각을 뜻하지 않는다.

## 발주 예측과 기존 계획 비교

발주 기본 예측은 XGBoost, 비교 기준은 D+3 Plan Reference(기존 ERP 계획)다. 기존 계획은 학습형 보조 모델이 아니다. 목표는 일별 최종 ERP 발주 계획량이며 실측 소비량·최적 재고량을 예측하는 모델로 설명하지 않는다. audited_v3에서 XGBoost의 기존 계획 대비 개선은 미확정이다. 이동평균이나 LSTM을 현재 기본·보조 운영 조합으로 설명하지 않는다.

발주 순위와 합계는 질문의 목표일·부품·선택 모델에 대한 SCREEN 조회 결과다. 서버는 표시된 차이의 절댓값을 내림차순으로 정렬하고, 소수 둘째 자리까지 같은 값이면 부품 번호 오름차순으로 정한다. 양수는 예측이 계획보다 큰 경우, 음수는 작은 경우다. 자동 발주 지시나 실제 계획 변경의 확정 탐지 결과가 아니라 검토 후보다. 과거 예시의 부품 순위·합계를 현재 답변에 재사용하지 않는다.

## 서로 다른 분석 영역의 범위

발주·용접 예지보전·배터리 품질은 서로 다른 시기에 수집한 독립 자료다. 세 영역의 수치를 하나의 공장 실시간 상태로 해석하거나 위험도 숫자를 직접 비교하지 않는다. 예지보전은 현시점 이상 탐지이며 미래 고장 시점·고장 확률·남은 수명을 제공하지 않는다. 품질 팩 화면의 저장 분석 결과와 개별 시험의 모델 분석은 별개다.

## CSV 예측과 검토 기록

CSV 업로드는 고정된 발주 모델로 입력 자료를 시험하는 기능이다. 업로드로 재학습하거나 공식 시드를 변경하지 않는다. 업로드 결과가 곧바로 공식 분석의 검토 기록으로 저장되는 흐름은 아니다. 공식 부품·목표일·모델의 검토 기록은 별도 검토 화면에서 사용자가 확인해 저장한다. 입력 날짜 정렬과 이월 표시는 발주 CSV 계약을 따라야 한다.

Copilot은 근거 조회, 답변, 검토 화면 연결과 초안 생성을 보조한다. 답변만으로 업무 기록 저장·발주 변경·설비 조치·출하 승인을 완료하지 않는다. 작업자 판정은 모델 예측 및 정답 라벨과 구분한다. 기록 조회 실패를 미확인 0건으로 해석하지 않는다. 분석 버전이 달라진 과거 판정은 재확인이 필요하다.

## 확인 근거

공식 자료 버전과 문서 범위: `firestore/seed/manifest.json`. 발주 운영 조합: `발주량 예측 모델/src/service_policy.py`. 질문 대상·순위·수량 조회: `backend/copilot_search.py`, `backend/demand_ranking.py`. CSV와 기록 기능: `backend/main.py`.

# 발주량 audited_v3 평가와 한계

기준일 2026-11-05. 현재 발주 서비스는 audited_v3의 XGBoost 예측과 기존 D+3 계획을 비교한다. 예측 대상은 일별 최종 ERP 발주 계획량이다. 실측 소비량이나 최적 재고량이 아니다. XGBoost는 시간순 CV의 합산 MAE가 가장 작아 선택됐지만, 기존 계획보다 우수하다는 결론은 확정하지 않았다.

## 날짜 보정과 평가 범위

원본 17,364행·117개 부품에서 동일 부품·시각의 수량 충돌 306개 그룹(612행)을 확인해 Part 21·26을 격리했다. 나머지 일별 자료의 관측일 49일 중 17일은 공통 부품의 90% 이상에서 수량 82개 칸이 전 관측일과 같아 이월 의심일로 분류했다. 이는 자료 패턴에 따른 보정 가정이며, 제공자가 확인한 저장 시스템의 작동 방식은 아니다. 모든 부품이 완전히 같았다는 뜻도 아니다.

audited_v3는 이월 의심일의 계획 열을 추정 기준일에 맞춰 다시 정렬하고, 해당 날짜의 최종 수량을 정답에서 제외했다. 원본 로그가 없는 2021-10-31은 별도 보간일이다. 이월·보간일을 새로운 실측 정답으로 세지 않으며 정답 날짜는 32일이다. 과거의 잘못 정렬된 평가에서 나온 개선 주장은 현재 성능 근거로 사용할 수 없다.

시간순 외부 CV는 2회, 목표일은 2021-10-14~10-21의 유효 7일이며 111개 부품·743건이다. 내부 검증은 4일, 최소 학습은 5일이다. 회고는 2021-10-25~11-01의 유효 6일, 109개 부품·643건이다. 회고 기간은 과거 실험에서 이미 관측했으므로 새로운 독립 시험으로 설명하지 않는다. 학습 목표일은 다음 검증·평가의 입력 기준일보다 앞서도록 분리했다.

## CV 7일과 회고 6일의 오차

다음 MAE·RMSE는 개수 단위이며 낮을수록 작게 틀린 것이다. CV 열은 743건, 회고 열은 643건의 행 단위 집계다.

## 기존 계획 대비 개선은 미확정

XGBoost의 CV MAE는 15.94, 기존 계획은 16.20으로 차이가 작다. 반면 CV RMSE는 XGBoost 34.74, 기존 계획 31.95로 기존 계획이 더 작다. 현재 자료에서는 기존 계획이 강한 기준이며, XGBoost는 그 계획을 보정하는 후보로 해석한다. 평균 오차 감소만으로 큰 오류·발주 비용·현장 효과까지 개선됐다고 말하지 않는다.

CV 7일과 회고 6일을 합친 13일 중 XGBoost가 기존 계획보다 일별 MAE가 작은 날은 9일이다. 날짜별 MAE 차이의 평균은 -1.114개이며 날짜 단위 4,000회 bootstrap의 95% 구간은 -3.0694~+1.0209다. 0을 포함하므로 개선은 미확정이다. 이 13일 통계는 위 CV 7일의 합산 MAE와 집계 범위·방식이 다르다.

같은 13일에서 7일 이동평균은 기존 계획보다 일별 MAE가 작은 날이 0일이며, 일별 MAE 차이 평균은 +13.003개(95% 구간 +8.0617~+19.8287)다. LSTM은 13일 중 3일에서만 기존 계획의 일별 MAE보다 작다. 이 결과로 이동평균 또는 LSTM을 현재 운영 기준으로 추천하지 않는다. 새로운 기간·현장 자료가 없어 일반화 성능과 업무 효과는 검증되지 않았다.

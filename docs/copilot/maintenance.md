# 예지보전 — 현재 모델·경보·평가 근거

기준일은 2026-11-05이며 공식 자료 버전은 `2026-11-05.v5`다. 예지보전 모델 버전은 `track-b-audited-v3`, 경보 정책 버전은 `maintenance-alarm-v3`다. 이 문서는 현재 레이저 용접 이상 탐지의 해석 기준이다. 선택 시험·모델의 수치와 경보 건수는 질문 대상의 공식 조회 결과를 사용한다.

## 현재 모델의 역할

예지보전 기본 조합은 지도 `LogisticCurrent`와 비지도 `RobustPhaseZ`의 OR다. 둘 중 하나가 이상으로 판단하면 해당 행을 경보로 집계한다. `RobustPhaseZ`는 정상 학습 구간에서 공정 위치별로 계산한 출력 중앙값과 robust 척도에 대한 이탈을 탐지한다. 현재 측정값을 사용하는 이상 탐지이며 미래 고장 시각이나 잔여수명(RUL)을 예측하지 않는다.

예지보전 모델은 개발 검증 구간의 이벤트 누락, FN, 오경보 이벤트, F1, FP 순으로 선택했다. 동률에서는 사전 정의한 단순성 순서를 적용해 `RobustPhaseZ`를 선택했다. 회고 시험 성적이나 학습시간으로 선택한 것이 아니다. 화면에서 다른 지도·비지도 모델을 선택하면 그 조합의 결과를 별도로 해석한다.

## 경보·위험도 해석

예지보전 사이클은 `PageNo` 1~39의 39행이며, 한 행 이상 경보이면 경보 사이클이다. 이벤트는 첫 양성 행에서 시작하고 정상 행에서 끝난다. 원본 행 누락, 파일 변경, 시간 역전·중복 또는 120초 초과 수집 공백도 이벤트를 분리한다. 사이클 경계만으로 이벤트를 끊거나 미래 행으로 경보를 평활화하지 않는다.

예지보전 화면의 위험도는 선택 모델의 점수를 각각 임계값으로 나눈 값 중 큰 값이다. 위험도 1은 임계값 수준이며 고장 확률 100%를 뜻하지 않는다. 행 수, 경보 사이클 수, 연속 이벤트 수는 서로 다른 집계 단위다. 모델·경보 정책·파이프라인 버전이 바뀌면 업무 확인 대상 ID도 달라진다.

## 검증된 범위와 한계

예지보전 개발 파일은 `WeldingTest_01_OK`, `WeldingTest_03_NG`이고 회고 시험 파일은 `WeldingTest_02_OK`, `WeldingTest_04_NG`다. 네 파일 모두 이전 실험에서 사용한 자료다. 주 평가의 정상 학습 자료는 `02_OK`보다 미래 자료를 포함하므로 전체 결과를 미래 시점 검증이나 새로운 외부 검증이라고 부르지 않는다.

예지보전 회고 시험에서 `RobustPhaseZ`의 행 단위 Precision은 0.9891, Recall은 1.0000, F1은 0.9945, FP는 3, FN은 0이다. 기본 `LogisticCurrent OR RobustPhaseZ` 조합의 사이클 Precision은 87.5%, Recall은 100%, F1은 0.9333, 정상 사이클 FPR은 2%다. 행 단위 성능과 사이클 단위 성능을 같은 지표처럼 비교하지 않는다.

예지보전 회고 시험의 이상은 하나의 연속 사건이다. 많은 이상 행을 탐지했어도 서로 독립적인 여러 고장을 검증한 것은 아니다. 모든 시험 이전의 정상 자료만으로 적합·보정한 별도 `RobustPhaseZ` 시간 검증에서는 `01_OK`와 `02_OK`의 정상 행을 모두 오경보 처리했다. 시간 변화에 대한 일반화 실패가 확인됐고 신규 사건·설비 외부 검증은 완료되지 않았다.

## 입력과 단위

예지보전 입력은 `PageNo`, `Speed`, `Length`, `RealPower`, `SetFrequency`, `SetDuty`, `SetPower`, `GateOnTime`, `WorkingTime`이다. `RealPower`는 W, `SetPower`와 `SetDuty`는 %, `Speed`는 mm/s, `Length`는 mm, `SetFrequency`는 Hz다. `GateOnTime`은 원문에 s로 표기되지만 실제 값 스케일과 단위는 현장 확인이 필요하다. W와 %인 두 출력을 직접 빼거나 비율로 만들지 않는다.

예지보전 CSV 재현은 고정된 기본 모델 조합을 사용한다. 5MB 이하, 최대 19,500행, 완전한 39행 사이클, 유한한 0 이상 숫자, 증가하는 유효 시각을 검사한다. 업로드 행을 자동 삭제·정렬·보간하지 않으며 출력 0도 보존한다. 학습 밖 레시피나 주파수·듀티 변경은 성능 미검증 조건으로 표시한다. 정답을 제공하면 원본 SHA-256과 행 ID를 검사하고 평가에만 사용한다.

예지보전 경보는 검토 우선순위의 근거다. 설비 정지·정비·안전 승인에 필요한 현장 SOP, 센서 단위 확인, 점검 비용과 미탐 위험을 반영한 임계값 승인은 별도로 확보해야 한다. Copilot은 경보 확인 기록이나 작업 지시가 실행됐다고 추정하지 않는다.

## 현재 근거 파일

현재 예지보전 정책과 결과의 원천은 `firestore/seed/maintenance.jsonl`, `runtime/maintenance/frozen.json`, `runtime/validation/maintenance_operational.csv`, `runtime/validation/maintenance_forward.csv`, `backend/maintenance_policy.py`, `backend/maintenance_engine.py`다. 연구 산출물 폴더 이름에 `track_b_final_v2`가 남아 있어도 현재 내부 모델 버전은 `track-b-audited-v3`다.
